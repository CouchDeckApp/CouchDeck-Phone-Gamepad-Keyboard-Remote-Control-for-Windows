# CouchDeck

[English](README.md) · **简体中文** · [日本語](README.ja.md) · [Español](README.es.md)

**把手机浏览器变成 Windows 电脑的手柄、键盘和触控板。**

电脑上安装，手机上扫码。打开浏览器，就能一边看电脑画面，一边用双摇杆玩游戏，或切到键盘和触控板操作桌面。手机无需安装专用 App，不需要注册账号。

手柄上的 L3/R3、日语键盘的「変換」、德语键盘的 AltGr、电脑输入法的候选词——这些小东西，也一起搬到了手机上。

Windows x64 · Android / iPhone 浏览器

## 键盘这件小事，做了 12 种配列

不只是把菜单翻译一下。熟悉的字母位置、当地常用的符号，以及输入法专用键，都值得在手机上有自己的位置。

| 配列 | 一些容易被忽略的小细节 |
| --- | --- |
| 美式 US、英式 UK | 分开处理 `£`、`@`、引号和 `#` 的位置 |
| 日语 JIS 106/109 | 假名键帽、`¥` / `ろ` 专用键，以及「半角/全角」「変換」「無変換」「英数」「かな」 |
| 韩语两套式 | 辅音、元音、Shift 双辅音层，还有 `한/영` 与 `한자` 键 |
| 标准注音、仓颉 / 速成字根 | 注音符号、声调和仓颉字根直接印在键帽上 |
| 德语 QWERTZ、法语 AZERTY | 不同的字母排列、重音字符和 AltGr 符号层 |
| 俄语 ЙЦУКЕН | 西里尔字母、`Ё`、本地标点，以及 Shift / Caps Lock 对应键帽 |
| 巴西葡语 ABNT2 | `Ç`、重音键和额外的物理键位 |
| 西班牙西语、拉美西语 | 两套分别适配，保留各自的标点与重音位置 |

按下 Shift、Caps Lock 或 AltGr 时，键帽会随之显示对应字符。配列与界面语言可以分别选择：用中文菜单，也可以操作日语键盘。

手机配列应与 Windows 当前使用的配列相匹配；文字组合和转换交给电脑上原有的输入法。

## 电脑在选词，手指在手机上选

开启「在手机显示电脑候选词」后，电脑输入法弹出的候选可以出现在手机键盘旁，直接点选。

比如用微软拼音选汉字、用微软日语输入法选转换结果，不用再盯着缩小的桌面，把鼠标一点点挪进候选框。没有候选时，这条选词栏会收起来，不挤占字母按键的位置。候选功能需电脑输入法支持。

![日语键盘与电脑输入法候选词](assets/japanese-keyboard.png)

## 双摇杆，也有“按下摇杆”

Windows 端提供虚拟 Xbox 360 手柄，可用于支持这类手柄输入的 PC 游戏。双摇杆、ABXY、十字键、肩键、扳机、Back 和 Start，都能在手机上操作。

**L3/R3 也能按。** 快速双点对应摇杆，第二下按住，再继续推摇杆，就能同时发送摇杆按压与方向——例如游戏里的按住冲刺并移动。

摇杆是连续方向输入，不只是四个方向按钮；双摇杆和多个按键可以同时操作，横屏、竖屏都有对应布局。切到键盘处理点事情，再回来，手柄不会因为切页就反复插拔。

## 横着拿，就用横着拿的键盘

竖屏是键盘搭配下方触控板；横屏则变成围绕电脑画面的左右分体键盘，两个拇指各管一边。

- **键盘高度与触控板高度分别调整**，按自己的屏幕和手指习惯分配空间，并保存在当前浏览器。
- **Ctrl、Alt、Win 可以点一下保持按住**，再点字母完成 `Ctrl+C`、`Ctrl+V` 等操作，不必一直用一根手指压住修饰键。
- **Shift 支持一次性大写**，输入完自动释放；需要连续大写时使用 Caps Lock。
- **Esc、Tab、方向键、Home/End、Page Up/Down、Insert/Delete** 等电脑按键也有自己的入口。
- **Fn 可以把数字行切成 F1–F10**，不必临时去找电脑键盘。

## 熟悉的触控板手势，也带来了

![竖屏键盘与触控板](assets/keyboard-trackpad.png)

轻点、双击、右键、拖拽，都可以在手机触控板上完成。双点后第二下不抬手，继续滑动就能拖动窗口或文件；双指既能上下滚动，也能左右滚动。

画面里的字太小，可以双指放大并平移查看，也可以直接触控电脑画面。指针移动灵敏度可调整；当前控制期间，还能调整电脑指针大小与支持的显示器缩放，让小屏上的目标更容易看清。

## 还有一些日常会用到的东西

- **10 种界面语言**：简体中文、繁體中文、English、日本語、한국어、Русский、Español、Deutsch、Français、Português。
- **局域网内使用，不需要注册账号或联网激活**。电脑用网线、手机用 Wi-Fi 也可以；连接记住后，不必每次从扫码开始。
- **收起电脑主窗口，仍可在后台提供控制**。正在使用时会请求 Windows 保持唤醒。
- **自带诊断、组件修复与故障报告导出**，出了问题可以从软件里查看，而不是先到各处找日志。

另外，手机界面里还藏了一个 2048。找到了可以玩一局。

## 快速开始

新电脑可能显示**「未知发布者」**。如 SmartScreen 阻止运行，请先确认安装器来自本仓库 Releases，再选择**「更多信息」→「仍要运行」**。不要关闭 Windows 安全防护。

1. 在电脑上安装并打开 CouchDeck，按提示完成首次配置。安装组件时可能需要确认 Windows 管理员权限。
2. 让手机和电脑连接同一局域网。电脑可以使用网线，手机连接同一路由器的 Wi-Fi。
3. 用手机扫描电脑界面的二维码，在浏览器中打开并点击连接。

连接后，可以在手机界面切换手柄、键盘和触控板。电脑画面也会显示在手机上。

## 运行环境

- **电脑**：Windows 10 1809 或更新版本、Windows 11，x64 架构。请安装系统可用的累积更新。
- **手机**：Android 或 iPhone，使用较新的浏览器。可先使用 Chrome 或 Safari；部分扫码 App 的内置浏览器可能影响连接或画面播放。
- **网络**：手机能够访问电脑所在的局域网。访客 Wi-Fi 或路由器的设备隔离设置可能阻止连接。

串流效果取决于电脑的编码能力、手机浏览器和局域网质量。

## 网络与通知

CouchDeck 会获取版本通知与开发者动态，不会自动下载或安装新版软件。局域网控制在没有互联网连接时仍可使用。

## 遇到问题？

反馈故障时，请在电脑端「诊断」中点击「导出故障报告」，将导出的**报告文件（`.txt`）作为邮件附件**发送到 [CouchDeck.HelloDev@outlook.com](mailto:CouchDeck.HelloDev@outlook.com)，附上问题现象、发生时间及复现步骤。涉及手机时，请注明型号和浏览器；截图可作为补充。

报告可能包含电脑名、文件路径和网络信息，不建议发在公开 Issue 中。功能建议或者其它的界面语言/特定用途的新增键盘布局可以在 Issues 中提出。
